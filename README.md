# Insomnia or sleep apnea? A sorting worksheet before you book CBT-I

A sorting worksheet to tell insomnia from sleep apnea before you book CBT-I, citing NHLBI, MedlinePlus and AASM.

This is a free, standalone mini-resource. The live HTML page is intended to be served from:

- Render: `https://insomnia-or-sleep-apnea-sorter.onrender.com/`
- GitHub Pages: `https://ahmetalkan.github.io/insomnia-or-sleep-apnea-sorter/`

It cites public pages on [sleepclinicguide.com](https://sleepclinicguide.com/) and official reference sources listed at the bottom of the page. Nothing here is a substitute for advice from a qualified professional.
